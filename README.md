# Moscow Student's League

Исходный код сайта [cup.rut-miit.su](https://cup.rut-miit.su) — межвузовской студенческой киберспортивной лиги Москвы.

Участники нового сезона:

- РУТ (МИИТ)
- НИУ МГСУ
- Финансовый университет
- МГТУ им. Н. Э. Баумана

## Стек

- React 18 + TypeScript
- Vite
- PHP API
- Caddy
- Node test runner

## Локальный запуск

```bash
npm ci
npm run dev
```

## Проверка и сборка

```bash
npm test
npm run build
```

## Структура

- `src/` — клиентское приложение
- `api/` — PHP API
- `public/` — PWA и статические ресурсы
- `tests/` — регрессионные и smoke-тесты
- `scripts/` — сборка, атомарный deploy и smoke-проверка
- `docs/` — эксплуатационная и проектная документация

Рабочие данные турниров, локальные конфиги и служебные миграционные скрипты в публичный репозиторий не входят.
